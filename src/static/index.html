GameLog API

Documentação do serviço RESTful responsável pelo gerenciamento de usuários, autenticação, avaliações, coleções, favoritos e seguidores da plataforma GameLog.

ENDEREÇO-BASE http://localhost:3000
AUTENTICAÇÃO JWT • Bearer Token
FORMATOS JSON e multipart/form-data

Usuários

Método Exemplo Descrição Resultado
GET GET /usuario Retorna a lista de usuários cadastrados. Não exige autenticação. 
[{ "id_usuario": 1, "username": "jogador", "nome": "Nome" }, ...]
GET GET /usuario/me Retorna os dados do perfil do usuário autenticado. Requer token JWT. 
{ "nome": "Nome", "username": "jogador", "data_nasc": "2008-05-10", "bio": null, "id_imagem_perfil": null }
GET GET /usuario/2 Busca o perfil público de um usuário pelo ID (por exemplo, 10). Não exige autenticação. 
{ "id_usuario": 10, "username": "jogador", "nome": "Nome", "email": "usuario@email.com", "bio": null }
POST POST /usuario Cadastra um usuário. Requer username, nome, data_nasc, email e senha. bio e foto são opcionais. A foto deve ser enviada no campo foto. O cadastro valida idade mínima de 14 anos e senha com pelo menos 8 caracteres. 
{ "id_usuario": 1, "username": "jogador", "nome": "Nome", "email": "usuario@email.com", "bio": null, "admin": false }
POST POST /usuario/login Efetua login. Requer login e senha no corpo da requisição. O campo login aceita username ou e-mail. 
{ "token": "JWT...", "usuario": { "id_usuario": 1, "username": "jogador", "nome": "Nome" } }
PUT PUT /usuario/10 Atualiza o perfil do usuário de ID 10. Requer autenticação e permite alterar somente o próprio perfil. Os campos username, nome, data_nasc, email, bio e foto são opcionais; os campos não enviados devem ser mantidos. A foto é enviada como foto. 
{ "msg": "Usuário atualizado com sucesso" }
DELETE DELETE /usuario/10/foto Remove a foto de perfil do usuário de ID 10. Requer autenticação e permissão sobre o próprio perfil. 
{ "msg": "Foto removida com sucesso" }
DELETE DELETE /usuario/10 Exclui o usuário de ID 10. A rota foi implementada com a intenção de permitir a exclusão pelo próprio usuário ou por um administrador. Requer autenticação. 
{ "msg": "Usuário deletado com sucesso" }

Coleção de jogos

Método Exemplo Descrição Resultado
GET GET /usuario/me/colecao Retorna os jogos da coleção do usuário autenticado, incluindo as informações de cada jogo. Requer token JWT. 
[{ "id_jogo": 1, "nome": "Jogo", "descricao": "...", "status": "quero_jogar", "favorito": false }, ...]
GET GET /usuario/me/colecao/favoritos Retorna somente os jogos marcados como favoritos pelo usuário autenticado. Requer token JWT. 
[{ "id_jogo": 1, "nome": "Jogo", "descricao": "...", "favorito": true }, ...]
PATCH PATCH /usuario/me/colecao/10/favorito Marca ou desmarca o jogo de ID 10 como favorito na coleção do usuário autenticado. Requer o atributo favoritar (boolean) no corpo da requisição. 
{ "msg": "Favorito atualizado com sucesso" }
PATCH PATCH /usuario/me/colecao/10 Altera o status do jogo de ID 10 na coleção do usuário autenticado. Requer o atributo status, que deve ser um dos valores: quero_jogar, jogando, finalizado ou abandonado. 
{ "msg": "Status atualizado com sucesso" }
GET GET /usuario/10/colecao Retorna a coleção pública do usuário de ID 10. Não exige autenticação. 
[{ "id_jogo": 1, "nome": "Jogo", "descricao": "..." }, ...]
POST POST /usuario/me/colecao/10 Adiciona o jogo de ID 10 à coleção do usuário autenticado. O status inicial é quero_jogar e o jogo começa como não favorito, conforme os valores padrão do banco. 
{ "msg": "Jogo adicionado à coleção com sucesso" }
DELETE DELETE /usuario/me/colecao/10 Remove o jogo de ID 10 da coleção do usuário autenticado. Ao remover a relação, o jogo também deixa de ser favorito para esse usuário. 
{ "msg": "Jogo removido da coleção com sucesso" }

Seguidores

Método Exemplo Descrição Resultado
GET GET /usuario/10/seguidores Retorna a lista de usuários que seguem o usuário de ID 10. Não exige autenticação. 
[{ "username": "jogador1" }, { "username": "jogador2" }, ...]
GET GET /usuario/10/seguindo Retorna a lista de usuários que o usuário de ID 10 está seguindo. Não exige autenticação. 
[{ "username": "jogador1" }, { "username": "jogador2" }, ...]
POST POST /usuario/me/seguindo/10 Faz o usuário autenticado seguir o usuário de ID 10. Requer token JWT. Se já existir essa relação, a rota retorna conflito. 
{ "msg": "Usuário seguido com sucesso" }
DELETE DELETE /usuario/me/seguindo/10 Remove a relação de seguimento entre o usuário autenticado e o usuário de ID 10. 
{ "msg": "Deixou de seguir o usuário com sucesso" }

Jogos

Método Exemplo Descrição Resultado
GET GET /jogo Retorna todos os jogos cadastrados, incluindo suas respectivas plataformas, gêneros e desenvolvedoras relacionadas. Não exige autenticação. 
[
    {
        "id_jogo": 1,
        "nome": "Exemplo",
        "descricao": "Descrição do jogo",
        "data_lancamento": "2024-01-01",
        "id_imagem": null,
        "plataformas": [...],
        "generos": [...],
        "desenvolvedores": [...]
    }
]
GET GET /jogo/10 Busca um jogo específico pelo ID (por exemplo, 10). Retorna seus dados, além das plataformas, gêneros e desenvolvedoras relacionadas. Não exige autenticação. 
{
    "id_jogo": 10,
    "nome": "Exemplo",
    "descricao": "Descrição do jogo",
    "data_lancamento": "2024-01-01",
    "id_imagem": null,
    "plataformas": [...],
    "generos": [...],
    "desenvolvedores": [...]
}
POST POST /jogo Cadastra um novo jogo. Somente administradores podem realizar essa operação. Requer nome, descricao, desenvolvedores, generos e plataformas. Os campos data_lancamento e foto são opcionais. Os relacionamentos devem ser enviados como arrays em formato JSON. A imagem deve ser enviada no campo foto. 
{
    "msg": "Jogo adicionado."
}
PUT PUT /jogo/10 Atualiza os dados do jogo de ID 10. Somente administradores podem realizar essa operação. Os campos nome, descricao, data_lancamento e foto são opcionais. Os campos não enviados mantêm seus valores anteriores. A substituição da foto é feita pelo envio de uma nova imagem. As plataformas, gêneros e desenvolvedoras são alterados por rotas próprias. 
{
    "msg": "Dados alterados com sucesso.",
    "jogo": {
        "id_jogo": 10,
        "nome": "Exemplo atualizado",
        "descricao": "Nova descrição",
        "data_lancamento": "2024-01-01",
        "id_imagem": "uuid-da-imagem"
    }
}
DELETE DELETE /jogo/10 Exclui o jogo de ID 10. Somente administradores podem realizar essa operação. Também remove a imagem associada ao jogo, quando houver. As relações com avaliações, gêneros, plataformas e desenvolvedoras são removidas conforme as regras de exclusão do banco de dados. 
{
    "msg": "Jogo apagado com sucesso.",
    "jogo": {...}
}

Avaliações de um jogo

Método Exemplo Descrição Resultado
GET GET /jogo/10/avaliacoes Retorna as avaliações feitas para o jogo de ID 10, incluindo informações do jogo e dos usuários que avaliaram. Não exige autenticação. 
{
    "jogo": "Exemplo",
    "descricao": "Descrição do jogo",
    "avaliacoes": [
        {
            "usuario": "jogador1",
            "estrelas": 5,
            "feedback": "Ótimo jogo!"

    ]

{
    "msg": "Avaliação registrada com sucesso.",
    "jogo": {
        "nome": "Exemplo",
        "estrelas": 5,
        "texto": "Ótimo jogo!"
    }
}
PUT PUT /jogo/10/avaliacoes Edita a avaliação do usuário autenticado para o jogo de ID 10. Os atributos estrelas e texto são opcionais. O campo texto também pode receber null para remover o comentário. 
{
    "msg": "Avaliação editada com sucesso.",
    "jogo": {
        "nome": "Exemplo",
        "estrelas": 4,
        "texto": "Gostei bastante."
    }
}
DELETE DELETE /jogo/10/avaliacoes Exclui a avaliação do usuário autenticado para o jogo de ID 10. Não exige atributos no corpo da requisição. 
{
    "msg": "Avaliação apagada com sucesso."
}

Desenvolvedoras

Rotas responsáveis por consultar, cadastrar, editar e excluir desenvolvedoras, incluindo o gerenciamento de suas imagens. As operações de cadastro, edição e exclusão são restritas a administradores.

Método Exemplo Descrição Resultado
GET /desenvolvedora Lista todas as desenvolvedoras cadastradas. Retorna um array com os dados das desenvolvedoras. Caso não existam registros, retorna 404.
GET /desenvolvedora/:id Busca uma desenvolvedora pelo ID e apresenta os jogos associados a ela. Retorna os dados da desenvolvedora junto com um array de jogos. Retorna 404 caso não seja encontrada.
POST /desenvolvedora Cadastra uma nova desenvolvedora. Requer autenticação e permissão de administrador. Retorna 200 com uma mensagem de confirmação e os dados cadastrados.
PUT /desenvolvedora/:id Atualiza os dados de uma desenvolvedora. Requer autenticação e permissão de administrador. Retorna 200 com uma mensagem de confirmação e os dados atualizados.
DELETE /desenvolvedora/:id/foto Remove a imagem associada à desenvolvedora. Requer autenticação e permissão de administrador. Retorna 200 com a mensagem "Foto removida."
DELETE /desenvolvedora/:id Exclui uma desenvolvedora e sua imagem, caso exista. Requer autenticação e permissão de administrador. Retorna 200 com uma mensagem de confirmação e os dados da desenvolvedora excluída, sem o campo id_imagem.

Cadastro de desenvolvedora

Rota: POST /desenvolvedora

Formato: multipart/form-data

Autenticação: obrigatória, com permissão de administrador.

Atributo Tipo Obrigatório? Descrição
nome String Sim Nome da desenvolvedora. Não pode estar vazio ou já cadastrado.
descricao String Sim Descrição da desenvolvedora. Não pode estar vazia.
data_criacao Date Sim Data de criação da desenvolvedora. Deve ser uma data válida.
foto Arquivo Não Imagem da desenvolvedora. Aceita apenas arquivos de imagem de até 5 MB.

Exemplo de resposta:

{
    "msg": "Desenvolvedora adicionada.",
    "desenvolvedora": {
        "id_desenvolvedora": 1,
        "nome": "Nintendo",
        "descricao": "Empresa desenvolvedora de jogos.",
        "data_criacao": "1889-09-23",
        "id_imagem": "uuid-da-imagem"
    }
}

Edição de desenvolvedora

Rota: PUT /desenvolvedora/:id

Formato: multipart/form-data

Autenticação: obrigatória, com permissão de administrador.

Todos os atributos são opcionais. Caso um atributo não seja enviado ou esteja vazio, o valor anterior será mantido. O envio de uma nova foto substitui a imagem anterior.

Atributo Tipo Obrigatório? Descrição
nome String Não Nome atualizado da desenvolvedora.
descricao String Não Nova descrição da desenvolvedora.
data_criacao Date Não Nova data de criação. Deve ser válida quando enviada.
foto Arquivo Não Nova imagem da desenvolvedora, limitada a 5 MB.

Exemplo de resposta:

{
    "msg": "Dados alterados com sucesso.",
    "desenvolvedora": {
        "id_desenvolvedora": 1,
        "nome": "Nintendo",
        "descricao": "Nova descrição.",
        "data_criacao": "1889-09-23",
        "id_imagem": "uuid-da-imagem"
    }
}

Consulta de desenvolvedora por ID

Rota: GET /desenvolvedora/:id

Autenticação: não é necessária.

Além dos dados da desenvolvedora, a resposta apresenta os jogos associados a ela, contendo o nome e o ID da imagem de cada jogo.

Exemplo de resposta:

{
    "id_desenvolvedora": 1,
    "nome": "Nintendo",
    "descricao": "Empresa desenvolvedora de jogos.",
    "data_criacao": "1889-09-23",
    "id_imagem": "uuid-da-imagem",
    "jogos": [
        {
            "nome": "The Legend of Zelda",
            "id_imagem": "uuid-da-imagem-do-jogo"
        }
    ]
}

Remoção de imagem

Rota: DELETE /desenvolvedora/:id/foto

Autenticação: obrigatória, com permissão de administrador.

Corpo da requisição: não possui.

Remove o registro da imagem no banco de dados e o arquivo correspondente na pasta de uploads. A desenvolvedora permanece cadastrada.

Exemplo de resposta:

{
    "msg": "Foto removida."
}

Exclusão de desenvolvedora

Rota: DELETE /desenvolvedora/:id

Autenticação: obrigatória, com permissão de administrador.

Corpo da requisição: não possui.

Exclui a desenvolvedora do banco de dados e remove sua imagem, caso esteja cadastrada.

Exemplo de resposta:

{
    "msg": "Desenvolvedora apagada.",
    "desenvolvedora": {
        "id_desenvolvedora": 1,
        "nome": "Nintendo",
        "descricao": "Empresa desenvolvedora de jogos.",
        "data_criacao": "1889-09-23"
    }
}
